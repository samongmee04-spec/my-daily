# My Daily — คู่มือติดตั้ง Firebase + GitHub Pages

สมุดบันทึกส่วนตัว (PWA) เก็บ **ข้อความ + รูป** ไว้บน Firebase (ฟรี แผน Spark ไม่ต้องผูกบัตร) และมีสำเนาในเครื่องเสมอ
ใช้งานได้ทั้งตอนออฟไลน์ แล้วซิงก์อัตโนมัติเมื่อมีเน็ต · มีปุ่ม **ซิงก์ตอนนี้** และ **กู้คืนข้อมูลทั้งหมดจากคลาวด์** สำหรับตอนข้อมูลหาย

---

## ส่วนที่ 1 — สร้าง Firebase (ทำครั้งเดียว ~10 นาที)

**ขั้นที่ 1 สร้างโปรเจกต์**
1. เปิด https://console.firebase.google.com → **Create a project / เพิ่มโปรเจกต์**
2. ตั้งชื่อ เช่น `mydaily-maytee` → Continue
3. Google Analytics: **ปิด** (ไม่จำเป็น) → Create project → รอเสร็จ → Continue
4. ตรวจมุมล่างซ้ายว่าเป็นแผน **Spark (ฟรี)** — ไม่ต้องอัปเกรด

**ขั้นที่ 2 เปิดการเข้าสู่ระบบด้วย Google**
1. เมนูซ้าย **Build → Authentication** → Get started
2. แท็บ **Sign-in method** → เลือก **Google** → เปิดสวิตช์ Enable
3. Support email เลือกอีเมลของคุณ → **Save**

**ขั้นที่ 3 สร้างฐานข้อมูล Firestore**
1. เมนูซ้าย **Build → Firestore Database** → Create database
2. Edition: **Standard** · Location: **asia-southeast1 (Singapore)** (เปลี่ยนภายหลังไม่ได้) → Next
3. เลือก **Start in production mode** → Create

**ขั้นที่ 4 เอาค่า config มาใส่แอป**
1. ไอคอนเฟือง ⚙ ข้างคำว่า Project Overview → **Project settings**
2. เลื่อนลงหา **Your apps** → กดไอคอน **</>** (Web)
3. App nickname: `My Daily` (ไม่ต้องติ๊ก Firebase Hosting) → Register app
4. จะเห็นโค้ด `const firebaseConfig = { apiKey: ..., ... };` → คัดลอก **เฉพาะส่วนในวงเล็บปีกกา `{ ... }`**
5. เก็บไว้ก่อน — จะไปวางในไฟล์ `firebase-config.js` ในส่วนที่ 2 ขั้นที่ 3

**ขั้นที่ 5 ใส่กฎความปลอดภัย (รอบแรก)**
1. Firestore Database → แท็บ **Rules**
2. ลบของเดิมทั้งหมด → เปิดไฟล์ `firestore.rules` (อยู่ในชุดไฟล์ที่อัปโหลด) คัดลอกทั้งหมดมาวาง → **Publish**
3. ตอนนี้ยังมีคำว่า `PASTE_OWNER_UID_HERE` อยู่ = **ยังปิดทุกคน** (ปลอดภัย) จะกลับมาแก้ในขั้นที่ 6

## ส่วนที่ 2 — ขึ้น GitHub Pages (วิธีเดิมที่เคยทำ)

**ขั้นที่ 1 สร้าง repo**
1. เข้า https://github.com (บัญชี `samongmee04-spec`) → **New repository**
2. ชื่อ `my-daily` · เลือก **Public** · ติ๊ก Add a README ได้ → Create repository

**ขั้นที่ 2 อัปโหลดไฟล์**
1. แตกไฟล์ `MyDaily-Upload-GitHub.zip` ในคอมพิวเตอร์
2. ใน repo → **Add file → Upload files** → ลาก **ไฟล์ทั้งหมดในโฟลเดอร์** (ไม่มีโฟลเดอร์ย่อย) มาวาง → **Commit changes**

**ขั้นที่ 3 ใส่ config Firebase**
1. ใน repo กดไฟล์ `firebase-config.js` → ไอคอนดินสอ ✏ (Edit)
2. บรรทัดล่างสุด `window.MYDAILY_FIREBASE_CONFIG = null;` → เปลี่ยน `null` เป็นค่าที่คัดลอกจากส่วนที่ 1 ขั้นที่ 4 เช่น
   ```js
   window.MYDAILY_FIREBASE_CONFIG = {
     apiKey: "AIza...",
     authDomain: "mydaily-maytee.firebaseapp.com",
     projectId: "mydaily-maytee",
     storageBucket: "mydaily-maytee.firebasestorage.app",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
3. **Commit changes**

**ขั้นที่ 4 เปิด GitHub Pages**
1. repo → **Settings → Pages**
2. Source: **Deploy from a branch** · Branch: **main** · Folder: **/ (root)** → Save
3. รอ 1–3 นาที จะได้ลิงก์ `https://samongmee04-spec.github.io/my-daily/`

**ขั้นที่ 5 อนุญาตโดเมน GitHub ใน Firebase** (ไม่ทำ = ปุ่มเข้าสู่ระบบจะขึ้นข้อผิดพลาด)
1. Firebase → Authentication → แท็บ **Settings** → **Authorized domains** → Add domain
2. ใส่ `samongmee04-spec.github.io` (ไม่ต้องมี https:// และไม่ต้องมี /my-daily) → Add

**ขั้นที่ 6 เข้าสู่ระบบ + ล็อกฐานข้อมูลให้เป็นของคุณคนเดียว**
1. มือถือเปิดลิงก์ GitHub Pages ด้วย Chrome → แท็บ **ฉัน** → **เข้าสู่ระบบด้วย Google**
2. จะขึ้นว่า “ฐานข้อมูลยังไม่อนุญาตบัญชีนี้” (ปกติ) → กด **คัดลอก** ข้าง UID
3. Firebase → Firestore → **Rules** → แทน `PASTE_OWNER_UID_HERE` ด้วย UID ที่คัดลอก (คงเครื่องหมาย ' ' ไว้) → **Publish**
4. กลับมาที่แอป → กด **ซิงก์ตอนนี้** → สถานะเป็น “ซิงก์แล้ว” ✅

**ขั้นที่ 7 ติดตั้งเป็นแอปบนมือถือ**
- Chrome เมนู ⋮ → **เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป** (หรือแท็บ ฉัน → ติดตั้ง My Daily) → ได้ไอคอนกระเป๋าบนหน้าจอ

## ใช้งานซิงก์

| ปุ่ม / สถานะ | ความหมาย |
|---|---|
| ☁ สีเขียว (หน้าหลัก) | ซิงก์ครบแล้ว — แตะเพื่อซิงก์ซ้ำ |
| ☁ มีจุดส้ม | มีรายการรอส่ง จะส่งเองใน 2 วินาทีหรือเมื่อกลับมาออนไลน์ |
| ☁ ขีดฆ่า | ออฟไลน์ หรือยังไม่ได้เข้าสู่ระบบ (แตะเพื่อไปหน้าเข้าสู่ระบบ) |
| ฉัน → **ซิงก์ตอนนี้** | ส่งของใหม่ขึ้น + ดึงของใหม่ลง |
| ฉัน → **กู้คืนข้อมูลทั้งหมดจากคลาวด์** | ใช้เมื่อข้อมูลในเครื่องหาย / รูปหาย / เปลี่ยนเครื่อง — ดึงทุกอย่างกลับมา (ของในเครื่องที่ใหม่กว่าไม่ถูกทับ) |

- เปลี่ยนเครื่อง / ล้าง Chrome: เปิดแอป → เข้าสู่ระบบ → ข้อมูลกลับมาเอง
- แก้บันทึกเดียวกันจาก 2 เครื่อง: ฉบับที่แก้ **ล่าสุด** ชนะ
- ลบบันทึกในเครื่องไหน ก็ลบบนคลาวด์และเครื่องอื่นด้วย
- **ล้างข้อมูลในเครื่องนี้** (หน้าฉัน) ไม่ลบคลาวด์

## ขีดจำกัดของแผนฟรี (Spark)

- พื้นที่ Firestore 1 GB — รูปถูกย่อเหลือด้านยาว 1920px (~150–500 KB) → เก็บได้ประมาณ **2,000–5,000 รูป**
- อ่าน 50,000 / เขียน 20,000 ครั้งต่อวัน — ใช้คนเดียวไม่มีทางถึง
- ถ้าเกินโควตา Firebase แค่หยุดรับชั่วคราว **ไม่มีการเก็บเงิน** (แผน Spark ไม่ผูกบัตร)
- **ไม่มีวิดีโอ**: Firebase ไม่มีที่เก็บวิดีโอฟรี (Storage ต้องผูกบัตรตั้งแต่ ก.พ. 2026) จึงตัดฟีเจอร์วิดีโอออก

## อัปเดตแอปครั้งต่อไป

อัปโหลดไฟล์ชุดใหม่ทับใน repo (**ยกเว้น `firebase-config.js` ที่แก้แล้ว — อย่าอัปทับ**) ไฟล์ชื่อแปลก ๆ อย่าง `index-xxxx.js` ชุดเก่าลบทิ้งได้
ถ้ามือถือยังเห็นเวอร์ชันเก่า: ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง (service worker อัปเดตเอง)

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| กดเข้าสู่ระบบแล้วขึ้น “โดเมนนี้ยังไม่ได้เพิ่ม…” | ทำส่วนที่ 2 ขั้นที่ 5 |
| “ฐานข้อมูลยังไม่อนุญาตบัญชีนี้” | ทำส่วนที่ 2 ขั้นที่ 6 ข้อ 3 (UID ต้องตรงทุกตัวอักษร) |
| หน้าฉันไม่มีปุ่มเข้าสู่ระบบ ขึ้น “โหมดในเครื่อง” | `firebase-config.js` ยังเป็น null หรือพิมพ์ผิด — ตรวจว่ามี `{ }` และเครื่องหมาย `"` ครบ |
| หน้าต่าง Google ไม่ขึ้น | อนุญาตป๊อปอัปใน Chrome แล้วลองใหม่ |
| รูปไม่ขึ้นในเครื่องใหม่ | หน้าฉัน → กู้คืนข้อมูลทั้งหมดจากคลาวด์ |

## สำหรับนักพัฒนา

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # dist/ = ไฟล์ที่อัปโหลดขึ้น GitHub (แบนราบ ไม่มีโฟลเดอร์ย่อย)
npm run preview   # http://localhost:4173
```

- `src/store/posts.tsx` ข้อมูลในเครื่อง (localStorage + IndexedDB) · `src/store/sync.tsx` เครื่องยนต์ซิงก์ 2 ทาง
- `src/lib/cloud/firebase.ts` Firebase Auth + Firestore (`posts/{id}`, `photos/{postId__photoId}`)
- `firestore.rules` กฎเจ้าของคนเดียว · ไม่ต้องสร้าง index เพิ่ม
- ทดสอบ: `python tests/e2e.py` (โหมดในเครื่อง 36 รายการ) · `python tests/e2e_sync.py` (ซิงก์ 2 เครื่อง 23 รายการ)
